# EMS Platform — Планы разработки и архитектурный контекст Kilo

Каталог `.kilo/plans/` содержит планы сессий Kilo CLI, дорожные карты и архитектурные декомпозиции, синхронизированные с репозиторием [EMS-Platform-Plans](https://github.com/DeenoRepository/EMS-Platform-Plans).

## Состав планов и статус реализации

1. **`1788779726328-agent-project-guidelines.md`**
   - *Содержание:* Нормативное руководство для ИИ-агентов (`AGENTS.md`), границы модулей, модель ролей, запрет на несанкционированные действия с секретами и эксплуатационным контуром.
   - *Статус:* Зафиксировано в корневом `AGENTS.md`.

2. **`1788779726328-agents-review-fixes.md`**
   - *Содержание:* Закрытие дефектов и замечаний по первичным правилам разработки агентов (ужесточение безопасности, обязательные критерии проверок).
   - *Статус:* Внедрено в проектные правила.

3. **`1788779726328-ems-development-skills.md`**
   - *Содержание:* Адаптация и матрица 11 специализированных навыков разработки в `.kilo/skills/` (на базе claude-skills, адаптированных под air-gapped архитектуру EMS).
   - *Статус:* Развернуты в `.kilo/skills/`, зафиксированы в `AGENTS.md` (раздел 15).

4. **`1788784880617-ems-mvp-specification.md`**
   - *Содержание:* Спецификация ядра EMS MVP, базовые архитектурные решения (ADR-0001 Стек и монорепозиторий, ADR-0002 Аутентификация/авторизация/LDAP, ADR-0003 Инструментарий и офлайн-поставка).
   - *Статус:* Реализовано в `packages/contracts`, `packages/core`, `docs/specs/ems-core-mvp.md`, `docs/adr/`.

5. **`1788794181335-core-review-fixes.md`**
   - *Содержание:* Устранение замечаний архитектурного ревью ядра: мигратор PostgreSQL, персистентность сессий, модульная изоляция, DDL-миграции.
   - *Статус:* Закрыто в репозитории (миграция 001, тесты фасадов и репозиториев).

6. **`1788795491644-core-security-review-remediation.md`**
   - *Содержание:* Исправление уязвимостей безопасности сессий, гранулярные разрешения `modules.manage`, ротация сессий, миграция 002.
   - *Статус:* Закрыто в `packages/core` и `packages/contracts`.

7. **`1788798898301-core-stabilization-roadmap.md`**
   - *Содержание:* Дорожная карта стабилизации ядра: Gate A (верификация монорепозитория, границ пакетов, изоляции схемы), Gate B (чистый bootstrap, row-level locks, outbox).
   - *Статус:* Gate A и Gate B закрыты. Текущая PostgreSQL-приемка: `38/38`, PostgreSQL 16.15; независимое ревью блокеров не обнаружило. Offline/release readiness не заявляется.

8. **`1788931545962-project-completeness-audit.md`**
   - *Содержание:* Аудит полноты реализации MVP ядра: проверка выполнения D1–D6, запрет обхода инвариантов, границы пакетов, CLI миграций.
   - *Статус:* Реализовано в репозитории (D1–D6 закрыты).

9. **`1788932272700-provisioning-and-acceptance-honesty.md`**
   - *Содержание:* Устранение обхода provisioning, удаление fallback-строк подключения, CLI мигратора и строгая приёмка.
   - *Статус:* Закрыто в репозитории (CLI `migrate.ts`, скрипты деплоя, skip-тесты).

10. **`1788933439860-gate-b-postgres-acceptance.md`**
    - *Содержание:* Реальная PostgreSQL-приёмка ядра Gate B (concurrency барьеры, terminal-состояния provisioning, откат миграций, пагинация аудита).
    - *Статус:* Реализовано и повторно подтверждено после remediation на чистом стенде (`38/38` тестов пройдено, PostgreSQL 16.15).

11. **`1788954961709-adr-tooling-iam-approval.md`**
    - *Содержание:* Утверждение tooling для frontend/LDAP, уточнение session transport и делегирования ролей, реализация IAM-инвариантов и синхронизация статусов Gate B.
    - *Статус:* Реализовано; ADR-0004 и ADR-0005 утверждены 2026-09-09. Gate B закрыт после PostgreSQL-приемки и независимого remediation-review.

## Локальное размещение планов

- В текущем проекте: `.kilo/plans/*.md`
- В глобальном хранилище Kilo: `~/.local/share/kilo/plans/*.md` (Linux) / `%LOCALAPPDATA%\kilo\plans\*.md` (Windows)
- Исходный репозиторий: `https://github.com/DeenoRepository/EMS-Platform-Plans`
